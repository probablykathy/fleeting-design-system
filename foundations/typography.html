Typography

Two typefaces, one rule: Inter for everything a person reads as interface text; JetBrains Mono reserved for identifiers, code, and data — session names, costs, timestamps, class names. This page absorbs the component catalogue's former "Typography" entry, since a type scale is a foundation, not a component.

Partial inconsistency, documented rather than hidden: this page's own <h1> renders at 20px/700 (see .intro h1 in docs.css, ported unchanged from the source file). As of the latest Heading update, the size now matches the 20px "Heading" specimen above — only the weight still differs (700 for page titles vs. 800 for the Heading specimen). The catalogue never formalized a single heading style — it's an organically-grown set of sizes and weights, not a strict scale. Worth resolving in a future pass, not silently picked one way or the other here.
