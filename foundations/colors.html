Colors

Every color in the system is an HSL custom property, referenced as hsl(var(--token)) — never a hardcoded value. Each swatch below shows its light value and its dark value side by side, independent of the site's current theme toggle, so both are visible at once.

01

Background & surface

--background
L 0 0% 100% · D 0 0% 0%
--foreground
L 240 10% 3.9% · D 0 0% 92%
--card
L 0 0% 100% · D 0 0% 6%
--card-foreground
same as --foreground
--popover
L 0 0% 100% · D 0 0% 6%
--popover-foreground
same as --foreground
02

Primary, secondary, muted, accent

--primary

--primary-foreground
L 0 0% 98% · D 0 0% 6%
--secondary
L 240 4.8% 95.9% · D 0 0% 11%
--secondary-foreground
same as --primary
--muted
same as --secondary
--muted-foreground
L 240 3.8% 46.1% · D 0 0% 62%
--accent
L 240 4.8% 95.9% · D 0 0% 14%
--accent-foreground
same as --primary

Chart

Defined in both themes. Only --chart-info is actually used today (chart bars, one avatar fill) — --chart-ok, --chart-warn and --chart-claim exist in the token set but aren't wired into any component yet. Documented here as-is rather than hidden.

--chart-warn unused
L 32 90% 40% · D 32 85% 60%
--chart-info
L 217 80% 56% · D 217 85% 70%
--chart-claim unused
