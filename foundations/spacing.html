Spacing

Honest gap in the system: there is no formal spacing scale or token today. Padding and gap values are hand-picked per component. This page documents the values as they actually occur in components.css — a first step toward a real scale, not a claim that one already exists.

Where each is used

ValueSeen in
4–6pxIcon-to-label gaps (Button, Toggle), checkbox/switch internal spacing
8–10pxBadge padding, most flex gaps between inline controls
12–14pxCard and alert internal padding, table cell padding
16–20px.demo and .card .ch/.cb padding, dialog padding
22–26pxSection (.c) vertical rhythm, header height, context-menu zone padding

These cluster loosely around a 2px increment rather than the more common 4px/8px grid — close enough to read as intentional, not close enough to call a formal scale. Converging this into named tokens (--space-1 through --space-6, for example) is flagged as a Should-Improve item, not done here — it would touch every component's padding/gap declarations, which is out of scope for documentation.
