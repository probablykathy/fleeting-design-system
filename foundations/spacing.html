Spacing

The system runs on a formal 4px base grid: eight named tokens, --space-1 through --space-8, each a multiple of 4px. Every padding, margin, and gap in the component library is expected to resolve to one of these — no more arbitrary in-between values like the old 6px/9px/13px/18px/22px cluster this page used to describe.

01

The scale

Defined once in tokens.css (and mirrored in the source catalogue's own :root), theme-independent — spacing doesn't change between light and dark.

Principle: every spacing value is a multiple of 4px. Larger structural gaps that fall outside this eight-step range (the page's 120px bottom clearance, a 40px sidebar footer gap) still follow the same 4px rule — they're just written as plain 4-multiple pixel values rather than named tokens, since the scale above only formalizes the range actually reused across components.

02

Where each token is used

TokenSeen in

--space-2 (8px)Input/Select/Native-Select horizontal padding, table cell padding, most inline flex gaps
--space-3 (12px)Button default horizontal padding, Alert padding, Card footer padding, menu/command-palette padding
--space-4 (16px)Card header/body padding, Button-lg padding, Dialog/Drawer padding, sidebar-demo content padding
--space-5 (20px).demo and overlay-scrim padding, header/sidebar outer edge padding
--space-6 (24px)Context-menu drop-zone padding, chart-to-legend margin
--space-7 (28px)Main content area's side margin
--space-8 (32px)Main content area's top padding, Card illustration-adjacent rhythm
03

Non-4px values intentionally retained

Formalizing the grid didn't mean forcing every number onto it. A few values stayed off-grid on purpose:

ValueWhereWhy retained
1–2pxBadge vertical padding, alert icon/title optical nudges, accordion trigger edge padding, tab-track and calendar-grid guttersHairline optical adjustments below the smallest token (4px) — rounding up would be a 100%+ size increase in very small chrome (a badge's own height, a tab pill's inset), visibly changing proportions the request asked to preserve.
4–8px offsets in calc(100% + Npx)Tooltip, Hover Card, Popover, Select, Dropdown Menu, Navigation Menu, Date Picker — every anchored-popover gapExplicitly excluded as "positioning required for an interaction" — these offset a floating surface from its trigger; changing them shifts where the popover lands, not how much breathing room content has.
10px / 18px chart gapsBar, grouped-bar and stacked-bar Chart gaps between bars/columnsExcluded as chart dimensions — the gap between bars is part of the chart's visual data-density, not general layout spacing, per the audit's exclusion list.
