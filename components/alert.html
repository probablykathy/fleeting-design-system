Alert

An inline status banner in four variants — information, success, warning, and error — sharing one structure.

Anatomy

[div.alert.info|.success|.warning|.destructive] [svg icon] [div] [div.at — title] [div.ad — description]

Live preview

Success

Class reference

ClassWhat it does
.alertBase: bordered, 12px/14px padding, icon + text row.
.alert.info/.success/.warning/.destructiveEach sets a matching border tint, soft background tint, and icon/title color from one token.
.at / .adTitle (foreground, bold) and description (muted-foreground) inside the text column.

Interaction notes

None — static, no dismiss button, no auto-hide. For a transient version of the same information, see Toast.

Usage

When to use

Persistent, in-page status directly relevant to the content around it.

When not to use

A one-off, transient confirmation — use Toast, which disappears on its own.

Accessibility

No live-region announcementA dynamically-inserted Alert has no role="alert" or aria-live — a screen reader won’t be notified if one appears without a page reload.

Code

<div class="alert success"><svg>…</svg><div><div class="at">Success</div><div class="ad">42/42 passed.</div></div></div>
