Breadcrumb

A horizontal trail of links showing where the current page sits in a hierarchy.

Live preview

platform-team/sessions/refactor-auth-middleware

Class reference

ClassWhat it does
.crumbFlex row, 8px gaps, muted-foreground text.
.crumb aMuted link, darkens on hover.
.crumb .curThe current (last) segment — foreground-colored, not a link.

Interaction notes

None — static markup. This documentation site’s own top-of-page breadcrumb (visible above this heading) reuses this exact class.

Usage

When to use

Showing hierarchy depth the user can navigate back up through.

When not to use

A single-level page with no meaningful parent — skip it rather than showing a one-item trail.

Accessibility

No landmarkThe wrapper isn’t a <nav> with aria-label="Breadcrumb", so assistive tech can’t identify it as a breadcrumb trail specifically (this documentation site’s own usage does wrap it in <nav>, but the original component demo doesn’t).

Code

<div class="crumb"><a href="#">sessions</a><span>/</span><span class="cur">refactor-auth</span></div>
