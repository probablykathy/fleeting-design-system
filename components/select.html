Select

A custom-styled dropdown that matches the visual system exactly — trades native behavior for pixel control.

Anatomy

[div.select] [div.select-trig — current value + chevron] [div.select-list — absolute-positioned, hidden until .open] [div.select-opt] × N

Class reference

ClassWhat it does
.select-trigThe visible, clickable field — same height/border as Input.
.select-listPopover-shadowed option list, positioned absolutely below the trigger.
.select.open .select-listThe only rule that shows the list — toggled by JS.

Interaction notes

Clicking the trigger toggles .open on the wrapper. Clicking an option writes its text into the trigger’s value span and closes the list. A shared document-level click handler closes it on any outside click.

Usage

When to use

Visual consistency with the rest of the system matters more than native platform behavior, and the option list is short.

When not to use

Whenever accessibility matters more than pixel-perfect styling — prefer Native Select, which gets full keyboard/screen-reader support for free. See Guidelines.

Accessibility

No keyboard or screen-reader supportNo tabindex on the trigger, no role="listbox"/role="option", no arrow-key navigation, no typeahead. Mouse-only today.

Code

<div class="select-trig"><span>Sort by cost</span></div> <div class="select-list open"><div class="select-opt">Sort by cost</div></div>
