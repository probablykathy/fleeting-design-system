Command

A searchable command palette — type to filter a grouped list of attempts and actions by keyword.

Anatomy

[div.cmdk] [input — filter] [div.grp-l — group label] then [div.itm] × N, repeated per group

ClassWhat it does

.itmA single filterable row; .hide toggled by the search.

Interaction notes

Typing in the input lowercases the query and toggles .hide on every .itm whose data-k attribute doesn’t contain it — a simple substring filter, not fuzzy matching. There’s no keyboard up/down selection, no Enter-to-run, and no global shortcut (like ⌘K) to open it — in this source it’s presented as an always-visible inline panel, not a real invokable overlay with its own open/close trigger.

Usage

When to use

A searchable list of many actions or records where typing to filter is faster than scrolling.

When not to use

A short, fixed list — Dropdown Menu is lighter for that.

Accessibility

No listbox/combobox semanticsNo role="listbox", no aria-activedescendant, no arrow-key or Enter handling — filtering works, but selecting a result does not.

Code

<div class="cmdk"><input placeholder="Search…"><div class="itm" data-k="promote">Promote</div></div>
