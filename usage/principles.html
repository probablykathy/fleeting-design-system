Principles

These are the rules actually evident in the implemented system — read out of the CSS and markup, not aspirational. Where the system breaks its own rule, that's named too.

Sharp geometry

Zero corner radius everywhere, with exactly two named exceptions: the circular avatar and the circular skeleton-loading placeholder. Nothing else rounds. See Borders & Radius.

Borders over shadows

Flat, in-page surfaces (Card, Button, Input, Table) separate from the page with a 1px border and no shadow. Shadow is reserved exclusively for surfaces that float above the page — menus, popovers, dialogs, tooltips. See Shadows.

Token-driven color, with two known exceptions

Almost every color reference in the system goes through hsl(var(--token)) — never a hardcoded value — so the same rule paints both themes. Two documented counter-examples, not smoothed over:

1. Several avatar examples set color:#fff directly instead of --primary-foreground.

2. Three of the ten status badges — .badge-discovery, .badge-review, .badge-issue — use hardcoded HSL literals with their own hand-written :root[data-theme="dark"] .badge-x dark-mode overrides, rather than reading from a token. This is the first place in the system where a component reaches around the token layer to handle its own dark-mode color directly. See Foundations → Colors for the exact values. This is recorded as a known exception to fix later, not treated as if the system were fully token-driven.

Two typefaces, one rule

Inter for interface text. JetBrains Mono is reserved for identifiers, data, and code — session names, dollar costs, timestamps — never for prose. See Typography.

True-black dark mode, by choice

Dark mode's background is pure black (0 0% 0%), not the softer dark-gray most shadcn-based systems default to. A deliberate, high-contrast stylistic decision, not an inherited default. See Dark.

Compact, data-dense sizing

Control heights cluster at 28 / 32 / 36px and body text sits at 11–13px throughout — a consistently tight, professional-tool density rather than a spacious, consumer-app one. Reflects the domain: session boards and verification reports, not marketing pages.
